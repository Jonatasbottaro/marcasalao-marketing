# Nova campanha Marca Salão

Consultar histórico integral e temas reservados no Postiz, cruzando-os com os READMEs e legendas locais. Se a consulta estiver incompleta, registrar pendência antes de gastar a API alegando tema inédito.

Preparar brief e gerar uma única arte pelo ComfyUI08, até uma chamada de imagem por pedido sem quantidade. Após timeout, consultar o mesmo prompt_id usando --resume, fila/histórico e cache. Não apagar estado ou trocar campanha para repetir a chamada.

Validar pacote, grafo, origem e bytes com marcasalao_media_guard.py antes de upload. Revisar imagem e legendas, enviar uma mídia compartilhada e conferir os dois DRAFT. Revisões atualizam os IDs existentes; não criam outro par. Remover duplicados exige autorização específica.
