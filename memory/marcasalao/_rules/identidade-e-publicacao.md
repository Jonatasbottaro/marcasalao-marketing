# Marca Salão: identidade e publicação

Escopo exclusivo Marca Salão. Destino: https://marcasalao.com.br. Preservar logo MS/tesoura, verde-petróleo, menta e referências aprovadas.

Uma campanha sem quantidade significa uma arte quadrada compartilhada e duas legendas. CTA neutra na imagem: Conheça o Marca Salão. Facebook recebe URL completa na legenda; Instagram promete link na bio somente após confirmar o link externo atual.

Pedido de conteúdo novo/processo completo permite seguir até dois DRAFT conforme o fluxo vigente. Pedido de ideias/prévia limita-se a essa etapa. Publicar/agendar exige autorização específica. Não criar recorrência nem alterar outras campanhas/marcas.
