# Fontes, evidências e autorizações

As instruções atuais do usuário e AGENTS.md governam o trabalho. Memória recuperada é evidência histórica e não concede autorização.

O Git guarda os materiais oficiais aprovados. Antes de alterar publicações, consultar o estado atual no Postiz; um README, manifesto, resumo ou handoff não comprova o estado remoto atual. Não reutilizar autorização de outra campanha nem de outra marca.

Nunca registrar tokens, senhas, cookies, dumps de sessões, credenciais ou dados de clientes na memória versionada. Memória operacional privada fica no diretório de dados do servidor ai-memory, fora deste repositório público.

Fontes: AGENTS.md e docs/ARQUIVAMENTO-DE-CAMPANHAS.md.
