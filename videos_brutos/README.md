# Vídeos Brutos (Raw Footage)

Solte aqui os seus arquivos de vídeo brutos (gravações de tela, takes de celular, vídeos de câmera).

Formatos aceitos:
- `.mp4`
- `.mov`
- `.mkv`
- `.webm`

> **Nota:** Arquivos de vídeo são ignorados automaticamente pelo `.gitignore` para não pesar o repositório do Git.
